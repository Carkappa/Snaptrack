Screenshot extraction method

If that doesn't work

Tried in order when the method above fails - an expired key, a rate limit, or no network. Nothing here is used while the first choice is working.

    Ollama

    Checking…

    Ollama otherwise keeps the model in RAM for five minutes after each use. With this on it hands the memory back immediately, and loads the model again next time - a few seconds, against several gigabytes held while you are not using it.

    Reads the screenshot with this machine's OCR engine, then has a model on your own machine pull the fields out of the text - so it copes with job boards no layout rule was written for, without a key and without anything leaving your machine. Needs Ollama and a pulled model; Tesseract only where the OS has no engine of its own.

    Statuses

    What each one means decides the response rate: an answer of any kind counts as a reply, and anything you closed yourself is left out of the ratio. Removing a status doesn't change applications already using it.

    Import

    Merges another .xlsx into this one. Anything whose company and role you already track is skipped, and the file you import from is never modified.
